# رحلة الوقار — نسخة كاملة تجريبية مع نقطة ربط تعديل الصور

## محتويات النسخة
- اللعبة الأصلية بأربعة مواقف، النقاط، التغذية الراجعة والصوت.
- مرحلة تصوير/اختيار صورة بعد انتهاء اللعبة.
- واجهة ربط خدمة تعديل صور حقيقية، ثم عرض النتيجة والاحتفال.
- وظيفة Netlify آمنة نسبيًا تحفظ مفتاح API على الخادم وليس في HTML.

## مهم قبل النشر
هذه حزمة جاهزة للربط وليست خدمة مجانية تلقائيًا. يلزم حساب API لدى مزود الصور، وقد تُحتسب تكلفة لكل تعديل. لا يمكن تشغيل التعديل الحقيقي حتى تضيفي مفتاح API إلى Netlify.

1. ارفعي **محتويات المجلد كاملة** إلى مستودع Git متصل بموقع Netlify، أو انشريها بطريقة تدعم Netlify Functions. رفع ملف `index.html` وحده إلى Netlify Drop لا ينشر الوظيفة الخلفية.
2. من إعدادات موقع Netlify افتحي Environment variables وأضيفي `OPENAI_API_KEY` بقيمة المفتاح السري، واجعلي نطاقه Functions إن توفر الخيار. لا تضعي المفتاح في ملف HTML أو ترسليه في المحادثة.
3. اختياريًا أضيفي `OPENAI_IMAGE_MODEL` إذا أردتِ تحديد نموذج آخر مدعوم في حسابك؛ الافتراضي في الوظيفة `gpt-image-2`.
4. أعيدي نشر الموقع بعد حفظ المتغيرات. اختبري الصورة أولًا بموافقة صاحبتها/ولي أمرها عند الحاجة.

## ملاحظات الخصوصية
- لا ترفع الصورة إلا بعد تفعيل مربع الموافقة.
- الوظيفة لا تحفظ الصورة في قاعدة بيانات، لكن الصورة ترسل إلى مزود خارجي لمعالجتها وقد تنطبق سياسة الاحتفاظ والمعالجة لدى المزود.
- لا تستخدمي صور طالبات قاصرات دون إذن واضح، ويفضل البدء بصورة اختبار غير حساسة أو صورة لشخص بالغ موافق.
- النتيجة قد لا تحفظ ملامح الوجه بالكامل؛ راجعيها قبل عرضها أو تنزيلها.

## تجربة الواجهة دون API
يمكن فتح `index.html` لمعاينة اللعبة. الكاميرا تحتاج عادة إلى HTTPS أو localhost. زر تعديل الصورة سيعرض رسالة خطأ/إعداد إذا لم تُنشر وظيفة Netlify مع المفتاح.
